EduTrack Pro அல்லது Class Tracker (அல்லது உங்கள் விருப்பத்திற்கேற்ப வைத்துக் கொள்ளலாம்)

🛠️ 1. தொழில்நுட்ப கட்டமைப்பு (Tech Stack)
செயலி உருவாக்கம் (Frontend):

Flutter (அல்லது React Native / Android Studio - Kotlin). குறிப்பு: Flutter பயன்படுத்தினால் ஒரே கோட் மூலம் ஆண்ட்ராய்டு மற்றும் ஐபோன் (iOS) இரண்டிலும் இயக்கலாம்.

தரவுத்தளம் & சேவையகம் (Backend & Database):

Firebase (Realtime Database / Firestore, Authentication, Cloud Messaging). இது இலவசமாகவும், எளிதாகவும் மாணவர்களின் தரவுகளை நிகழ்நேரத்தில் (Real-time) சேமிக்க உதவும்.

பயனர் வகைகள் (User Roles):

ஆசிரியர் (Teacher / Admin): பணிகளை வழங்குவது, மதிப்பீடு செய்வது, ரிப்போர்ட் பார்ப்பது.

மாணவர் (Student): தனக்குரிய வீட்டுப்பாடங்களைப் பார்ப்பது, முடித்ததை அப்லோட் செய்வது.

🚀 2. செயலியின் முக்கிய அம்சங்கள் (Key Features)
பாதுகாப்பான உள்நுழைவு (Authentication):

ஆசிரியர் மற்றும் மாணவர்களுக்கான தனித்தனி Login (Email/Password அல்லது Google Sign-in).

பணி மேலாண்மை (Task & Assignment Manager):

புதிய வீட்டுப்பாடம், அசைன்மென்ட், பிராஜக்ட் அல்லது தேர்வை பதிவேற்றம் செய்தல் (தலைப்பு, விவரங்கள், கடைசி தேதி / Due Date).

நிலை கண்காணிப்பு டாஷ்போர்டு (Status Tracking Dashboard):

முடிந்தவர்கள் (Completed): யார் எப்போது சமர்ப்பித்தார்கள்.

முடிக்காதவர்கள் (Pending): இன்னும் சமர்ப்பிக்காதவர்களின் பட்டியல்.

முன்னேற்றப் பகுப்பாய்வு (Progress & Analytics):

ஒவ்வொரு மாணவரின் செயல்திறன் மற்றும் முன்னேற்றத்தை গ্রாப் (Charts) வடிவில் காண்பித்தல்.

அறிவிப்புகள் (Push Notifications):

நாளை கடைசி தேதி உள்ள பணிகளுக்காக மாணவர்களுக்கு நினைவூட்டல் (Reminder) அனுப்புவது.

🗓️ 3. படிநிலைப் செயல்தட்டம் (Step-by-Step Implementation Plan)
கட்டம் 1: திட்டமிடல் & வடிவமைப்பு (Planning & UI Design - 1 வாரம்)
தேவை பகுப்பாய்வு: எந்தெந்த வகுப்புகளுக்கு இந்த செயலி தேவை என்பதைத் முடிவு செய்தல்.

UI/UX வடிவமைப்பு: எளிய மற்றும் தமிழ் மொழிக்கு ஏற்ற வடிவமைப்பு (Figma மூலம் ஸ்கிரீன் டிசைன் செய்தல்).

கட்டம் 2: தரவுத்தளம் மற்றும் ஃபிரண்ட்என்ட் உருவாக்கம் (Core Development - 2 முதல் 3 வாரங்கள்)
Firebase அமைப்பு: பயனர் தரவு மற்றும் பணிகள் சேமிக்க Database-ஐ உருவாக்குதல்.

ஆசிரியர் திரை (Teacher Screen):

டாஷ் போர்ட் (Dashboard) உருவாக்குதல்.

புதிய பணி (Task) சேர்க்கும் படிவம் (Form).

மாணவர்களின் நிலையைச் சரிபார்க்கும் பட்டியல் (List view with Status).செயலியின் வடிவமைப்பு & தொழில்நுட்பம்
ஆஃப்லைன் தரவுத்தளம் (Offline Local Database):

இணையம் தேவையின்றி தரவுகள் அனைத்தும் ஆசிரியரின் மொபைல் போனிலேயே பத்திரமாகச் சேமிக்க SQLite அல்லது Hive (Flutter) பயன்படுத்தலாம்.

பயன்பாட்டு தளம் (Tech Stack):

Flutter (எளிதாக ஆண்ட்ராய்டு ஆப்பாக மாற்றலாம்) அல்லது MIT App Inventor (மிகவும் எளிமையாகக் குறியீடே இல்லாமல் உருவாக்க விரும்புவோருக்கு).

ஆ) பணி வகையைத் தேர்ந்தெடுத்தல் (Task Category):

இ) விரைவு நிலைப்பதிவு (Quick Status Update):
ஒரு பாடப் பணியைத் தேர்ந்தெடுத்ததும், அந்த வகுப்பின் மாணவர்கள் பட்டியல் தோன்றும்.

பெயருக்கு அருகில் Tick (முடித்தார் - Green) / Cross (முடிக்கவில்லை - Red) பொத்தானை ஒரே டச் மூலம் பதிவு செய்யும் வசதி.

ஈ) முன்னேற்றம் & அறிக்கை (Reports & Progress Analytics):
தனிநபர் அறிக்கை (Student Progress): குறிப்பிட்ட மாணவர் இதுவரை எத்தனை பணிகள் முடித்துள்ளார், எதில் பின்தங்கியுள்ளார் என்ற விவரம்.

வகுப்பு அறிக்கை (Class Overview): ஒட்டுமொத்த வகுப்பில் எத்தனை சதவீதம் பேர் பணியை முடித்துள்ளனர் என்ற வரைபடம் (Pie Chart / Bar Chart).

Excel / PDF ஏற்றுமதி (Export Option): கண்காணிப்பு அறிக்கைகளை PDF அல்லது Excel ஃபைலாக உங்கள் போனில் சேமித்துக் கொள்ளும் வசதி.
